# 06 服务质量预测模型（MLP）

> 回答一个问题：**压测跑完之后，如何不上线就问出"某个没测过的负载点，服务质量会是多少？"**

## 1. 动机与定位

前三份文档解决"评估"：给定服务，测出最佳 SLA/SLO 设置、容量边界、水位边界。
但评估的产物是**离散压力级上的阶跃观测**——只知 8 并发达标、16 并发崩塌，
中间（10、12）与之外（24）都是空白。生产容量规划、路由配额、扩容评估需要的却是
**连续负载 → 连续质量**的映射。

本文档定义 SLA 分析器的第二种产出：**服务质量预测模型**。
压测采样（不同并发 × 不同请求长度）不再只是判定素材，同时是训练数据；
训练出一个多层感知机（MLP），输入请求数据特征与负载情况，输出 TTFT/TPOT 预测。

分析器的完整职责因此变为：

| 产出 | 回答 | 载体 |
| --- | --- | --- |
| 门限 + 容量 + 水位 | 当前服务的边界在哪里？ | 报告结论（docs 01-03、05） |
| 预测模型 | 任意负载点的质量是多少？ | `results/qos_model.npz` + 报告预测章节 |

## 2. 为什么是 MLP，为什么纯 Python 实现

**为什么 MLP**：时延对（并发 × 长度）的响应是带膝点的非线性曲面——排队论下
TTFT 在到达饱和前近似平坦、过膝后急剧抬升，且膝点位置随长度移动。线性/查表
都无法同时表达"平坦区 + 膝点 + 长度交互"。小 MLP（隐藏层 8-16、ReLU）足以拟合
这类曲面，且能自然输出两个头（TTFT/TPOT）对应 PD 分离的两个平面。

**为什么不用 numpy/框架**：本项目约束为纯 Python ≥ 3.11 标准库零依赖
（见 [00-overview](00-overview.md) D2）。数据规模（千～万样本）、网络规模
（三层、数百参数）下纯 Python 全批量 Adam 训练在分钟级可完成，引入框架属于
用高射炮打蚊子且破坏部署约束。**推理侧同样零依赖**：`--qos-predict` 可直接
在无 numpy 的环境里用训练好的模型做预测。

**.npz 互操作**：模型文件采用 numpy 的 `.npz` 容器（ZIP + `.npy` 成员），
因此训练产物可被任何 numpy 生态工具（分析脚本、可视化、上报平台）直接
`np.load()` 消费；格式由 `bench/npz.py` 用标准库实现，双向互通。

## 3. 数据口径：哪些样本进训练集

样本筛选规则与测量有效性文档（[04](04-measurement-validity.md)）一脉相承，
核心原则是**不引入偏差、不浪费信息**：

| 样本类型 | 是否入训练 | 理由 |
| --- | --- | --- |
| `status=ok` 且非预热 | ✅ | 正常样本 |
| `status=ok` 但 `latency_class=A3`（超门限） | ✅ | **必须保留**。膝点区只有 A3 样本；只训达标样本等于删除模型最需要学习的区域 |
| `is_warmup=1` | ❌ | 预热段未进入稳态 |
| `status=aborted` | ❌ | 被放弃的在途请求，时延不可信（存活者偏差） |
| `status=failed`（A1） | ❌ | 失败通常伴随超时/截断，`ttft/tpot` 缺失或畸变；硬水位由 A1 占比刻画，不由时延模型刻画 |
| 基线阶段（`kind='baseline'`） | ❌ | 并发为 1 的单点，入训会把模型往"理想无竞争"方向拉；基线数据另有门限用途 |

**特征**（请求时可观测/可设定的量，三重对数化）：

| 特征 | 说明 |
| --- | --- |
| `concurrency` | 本级闭合回路并发（负载强度的主驱动） |
| `prompt_tokens` | 实际 prompt 长度 |
| `completion_tokens` | 实际输出长度 |

**推理时的 completion_tokens 从哪来**：请求发出时输出长度未知，仿真/预测时从
训练集的经验输出长度分布（按长度桶）采样。这与"负载情况"的语义一致：
给定流量构成（prompt 分布 + 输出长度分布）+ 并发，预测质量。

**目标**：`y_ttft = log(ttft_ms + 1)`，`y_tpot = log(tpot_ms + 1)`。
时延是正的重尾量，对数化把乘法噪声变加法噪声、把饱和膝点变成可拟合的
单调曲面；`+1` 避免 log(0)。指标与预测值在报告里一律换算回毫秒。

## 4. 训练协议

```
输入特征 x = [log(c), log(p), log(o)]   （c=并发, p=prompt, o=completion）
        │  标准化（训练集均值/标准差，存入模型文件）
        ▼
  Dense(h1, ReLU) → Dense(h2, ReLU) → Dense(2, linear)
        │
        ▼
  ŷ = [ẑ_ttft, ẑ_tpot]（标准化 log 空间）→ 反变换 → 毫秒
```

- **网络**：默认隐藏层 `[12, 12]`，Xavier 初始化，全批量 Adam（lr=0.01，β=(0.9,0.999)），
  MSE 损失（标准化 log 空间）。
- **样本上限**：单级过量时按 stage 分层抽样封顶（默认 4000），保证纯 Python 训练
  时长可控（本机基准：4000 样本 + `[12,12]` + 4 折交叉验证 + 终训 ≈ 95s）；
  `max_train_seconds`（默认 150s）为硬预算，超时即停（用已训轮次）。
- **验证**：**按 stage 分组的 K 折**（默认 K=min(stage 数, 4)）。同级样本共享并发
  特征与时间相关性，随机划分会让验证集"见过"同并发分布、指标虚高；按 stage 分组
  保证每折的验证级在训练折里完全没出现过。stage 数 < 2 时无法交叉验证，此时
  只报训练集指标并明确标注"无有效验证"。
- **轮数选择**：取各折验证损失最优轮数的中位数，在全量数据上重训最终模型
  （小数据下折间最优轮数稳定，该规则简单且不泄漏）。
- **早停之外的诚实**：若最优验证 R² 低于阈值（见 `min_r2`），报告明确写
  "模型不具备预测价值"，预测章节只渲染数据口径不给结论。

## 5. 校准：从点预测到分位数与通过率

点预测只回答"典型值"。SLA/SLO 判定需要分布信息。做法：

1. 汇集所有折的**折外预测**（out-of-fold），得到残差
   `r = y_true − ŷ`（log 空间），排序后即残差 ECDF `F_resid`。
2. 任意分位数：`p_q(毫秒) = exp(ŷ + quantile(r, q))`。
3. **通过率**（把预测接到 SLA 判定的关键恒等式）：

```
P(时延 ≤ T) = P(r ≤ log T − ŷ) = F_resid(log T − ŷ)
```

   给定流量构成（各长度桶的 prompt/输出长度 + 权重）与并发，逐桶预测
   `F_resid`，按桶权重平均即该并发下的 TTFT/TPOT 通过率；两个通过率相乘
   即预测 SLO（A2 占比）。这把离散压力级间的空白填成了连续曲线，
    且不需要假设任何分布族（高斯假设在排队时延下不成立）。

## 6. 包络守卫：模型只在自己的数据范围内说话

训练数据覆盖的（并发 × 长度）矩形即**有效包络**。`predict()` 对超出包络
（含容差）的输入打 `extrapolated=True`；报告对外推行标注"外推"且
**不参与任何结论**。理由：

- 排队膝点之外时延可能超线性恶化，MLP 的平滑外推必然低估；
- 未测到的长度区间（如只测到 8192，问 32768）没有依据。

水位边界细扫（见 §7）只允许在包络内插值，不允许超过最大实测并发。

## 7. 与既有模块的关系

**容量模型**（[02](02-pd-capacity-model.md)）：容量边界原是离散压力级上的
连续前缀判定；模型提供级间插值——可回答"质量容量 8 与 16 之间，真实边界
更可能在哪"，并给出预测曲线供人工确认。

**水位**（[05](05-watermark.md)）：软/硬水位边界同样只有离散观测点。用模型在
包络内细网格扫描（步进 1 并发），预测 BUSY/OVERLOAD 临界点，与实测边界
互相印证；两者一致时水位结论的可信度显著提升，不一致时报告并列展示、
提示补测。

**PD 分离**：TTFT/TPOT 双头即两个平面的投影，与 A3 归因（TTFT 主导 →
prefill 平面压力，TPOT 主导 → decode 平面压力）使用同一套叙事，不需要新概念。

## 8. 模型文件格式（.npz）

单文件 `results/qos_model.npz`，ZIP 容器内每个成员是一个 `.npy` 数组：

| 键 | 形状 | 内容 |
| --- | --- | --- |
| `w1,b1,w2,b2,w3,b3` | 依网络 | 各层权重与偏置 |
| `feat_mean`, `feat_std` | (3,) | 特征标准化参数 |
| `tgt_mean`, `tgt_std` | (2,) | 目标标准化参数（log 空间） |
| `resid_sorted_ttft`, `resid_sorted_tpot` | (n,) | 折外残差排序值（ECDF） |
| `resid_q50/q90/q99_ttft`（及 tpot） | () | 残差分位数（便捷缓存） |
| `feat_min`, `feat_max` | (3,) | 训练包络（原始特征空间） |
| `meta_json` | (n,) uint8 | UTF-8 JSON：版本、特征名、目标名、网络结构、样本量、折指标、训练时间 |

`.npy` 为 numpy 序列化格式（魔数 `\x93NUMPY` + 版本 + 头字典 + 原始数据），
本实现只依赖标准库 `zipfile`/`struct`，读取时兼容 `<f8/<f4/<i8/<i4/u1`
与 1-2 维数组——即 numpy `np.savez_compressed` 产物的公共子集。

## 9. 局限与明确不做的事

1. **膝点 smear**：平滑激活的 MLP 在膝点附近会抹出渐变带，该邻域预测
   方差最大。缓解=残差 ECDF（分位数变宽）+ 包络警告，不是消除。
   容量结论仍以实测连续前缀规则为准（模型只做补全与解释）。
2. **绑定当次服务配置**：模型学到的是"该引擎 + 该模型 + 该并行配置"的
   曲面；换引擎/模型/TP 数必须重训（与 baseline_relative 门限同哲学）。
3. **不建模资源层**：KV Cache 占用、批 slot、GPU 利用率是服务端内部量
   （见 [05](05-watermark.md)），黑盒客户端不预测它们。
4. **不做在线推理**：训练在压测结束后一次性完成；模型用于规划与仿真，
   不进入请求路径。
5. **小数据纪律**：样本量低于 `min_samples` 不训练；R² 不达标不出结论。

## 10. 验证方法

- **单元**：npz 读写往返（含 dtype/shape 覆盖）；MLP 对合成函数
  （如 `log(1+c²)+0.5·log p`）的拟合精度随轮数下降；包络守卫触发；
  ECDF 通过率与解析分布对照（构造已知残差分布）。
- **端到端**（mock server）：跑多级压测 → 训练 → 报告渲染预测曲线；
  在已测并发上对比"预测 SLA/SLO vs 实测 SLA/SLO"，偏差应在残差
  分位数范围内；`--report-only` 从 DB + npz 完整重建；关闭开关时零渲染。
